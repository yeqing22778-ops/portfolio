写在 content/notes/ 里的 .md 文件会被编译成静态页面，构建之后不需要 JavaScript 也能读。

支持哪些写法

  • 粗体、斜体、删除线
  • 行内代码
  • 普通链接
  • 无序列表和有序列表

  2. 第二步

代码块

// 代码块里的内容会原样保留，不会被当成 HTML
const hello = (name) => `你好，${name}`;
console.log(hello('<script>不会执行</script>'));

引用

引用可以连着写多行。

怎么写一篇新的

  1. 在 content/notes/ 新建一个 .md 文件
  2. 顶部三行 --- 之间写标题、日期、摘要
  3. 保存，执行 npm run build

文件名会变成网址：my-note.md → /notes/my-note/。
网址只用得到小写字母和连字符，中文文件名会自动转成短哈希，不会重复。

图片

点一下图片会全屏放大，再点一下（或按 Esc）关闭。
